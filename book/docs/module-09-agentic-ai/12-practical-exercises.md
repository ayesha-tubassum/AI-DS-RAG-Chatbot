Complete these exercises before the final review.

## Beginner
1. Explain the difference between a chatbot and an agent.
2. Write a function that validates a numeric input.
3. Design a tool schema for searching a product list.
4. List three stopping conditions for a planning loop.
5. Create a structured handoff for a researcher role.

## Intermediate
6. Design a memory policy for a study assistant, including deletion and expiry.
7. Draw a Researcher–Writer–Reviewer workflow.
8. Define five test cases for an autonomous data analyst.
9. Compare a fixed workflow with a dynamic agent for monthly reporting.
10. Create a risk table for an assistant that reads files and drafts emails.

## Advanced
11. Plan an evaluation comparing one agent with three specialized agents.
12. Add a step budget, timeout, and structured error handling.
13. Design a reviewer checklist for unsupported claims.
14. Identify prompt-injection risks in retrieved documents and propose mitigations.
15. Write a README describing setup, tools, limitations, and responsible use.

## Evaluation Criteria
Answers should use clear definitions, practical examples, explicit limits, and testable requirements. Code should be tested with valid input, invalid input, missing data, and tool failures.
