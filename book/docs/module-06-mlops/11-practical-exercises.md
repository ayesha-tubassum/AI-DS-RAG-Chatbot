# Practical Exercises

## Beginner

1. Explain the difference between batch and real-time inference.
2. Create a `/health` endpoint in FastAPI.
3. Define a Pydantic request model with three fields.
4. Save and reload a scikit-learn model with `joblib`.
5. Write a basic Dockerfile for a Python application.

## Intermediate

6. Build a `/predict` endpoint around a previous ML model.
7. Add validation for invalid input values.
8. Add Python logging to your API.
9. Track two experiments with MLflow.
10. Create a CI workflow that runs tests.

## Advanced

11. Containerize the FastAPI service.
12. Add API tests.
13. Design a monitoring dashboard specification.
14. Explain how data drift could affect a deployed model.
15. Draw an end-to-end MLOps architecture for a model from Module 04 or 05.

## Reflection

For each exercise, record:

- What you implemented
- What failed
- How you fixed it
- What you learned
