# Module Review and Completion Checklist

## Concepts

- [ ] I understand ML deployment.
- [ ] I can explain batch vs real-time inference.
- [ ] I understand the role of FastAPI.
- [ ] I can create a prediction endpoint.
- [ ] I understand Docker images and containers.
- [ ] I can write a basic Dockerfile.
- [ ] I understand experiment tracking.
- [ ] I can log MLflow parameters and metrics.
- [ ] I understand CI/CD at a beginner level.
- [ ] I can explain logging and monitoring.
- [ ] I understand the purpose of data-drift monitoring.

## Projects

- [ ] FastAPI ML deployment project completed.
- [ ] MLflow tracking implementation completed.
- [ ] Dockerized ML microservice completed.
- [ ] Full deployment pipeline with monitoring completed.

## Portfolio Readiness

A strong portfolio submission should contain:

```text
project/
├── src/
├── tests/
├── model/ or training/
├── Dockerfile
├── requirements.txt
├── README.md
└── .github/
    └── workflows/
```

The README should explain setup, training, testing, API usage, and deployment.

## Module Completion

You are ready for the next module when you can take a trained model and explain how you would:

```text
Train → Track → Package → Serve → Test → Deploy → Monitor
```

That workflow is the central idea of MLOps.
