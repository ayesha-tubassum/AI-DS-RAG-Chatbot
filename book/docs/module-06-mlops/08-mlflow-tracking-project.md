# Class Project — MLflow Tracking Implementation

## Goal

Track multiple machine learning experiments using MLflow.

## Tasks

1. Choose a dataset.
2. Create at least three model experiments.
3. Change one or more hyperparameters between runs.
4. Log model parameters.
5. Log evaluation metrics.
6. Save or log model artifacts where appropriate.
7. Compare the runs.
8. Identify the best-performing experiment.
9. Document why the selected model was chosen.

## Suggested Experiment Table

| Run | Model | Key Parameter | Metric |
|---|---|---|---|
| 1 | Logistic Regression | C=1 | Record result |
| 2 | Logistic Regression | C=10 | Record result |
| 3 | Random Forest | Trees=100 | Record result |

Use your actual results rather than copying example numbers.

## Deliverables

- Training script/notebook
- MLflow run records
- Comparison table
- Best-model explanation
- Short README
