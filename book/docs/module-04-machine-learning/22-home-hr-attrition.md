# Home Project — HR Attrition Prediction

## Goal
Predict whether an employee belongs to an attrition class using historical organizational data.

## Possible Features
Job role, tenure, satisfaction, workload indicators, compensation-related variables, overtime, and training history.

## Workflow
```text
EDA → Preprocessing → Feature Engineering → Split
→ Classification → Evaluation → Interpretation
```

## Models
Try Logistic Regression, Decision Tree, Random Forest, and Gradient Boosting.

## Evaluation
Accuracy, precision, recall, F1-score, and confusion matrix.

## Responsible Use
Employee predictions should not become automatic employment decisions. Consider privacy, fairness, bias, transparency, and human oversight.

## Deliverables
Exploratory analysis, preprocessing pipeline, model comparison, feature analysis, responsible-use discussion, and final report.


## Syllabus Focus

Predict employee attrition with responsible interpretation.
