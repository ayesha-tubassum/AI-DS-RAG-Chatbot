# Class Project — House Price Prediction

## Goal
Build an end-to-end regression system to predict house prices.

## Suggested Fields
`area`, `bedrooms`, `bathrooms`, `location`, `age`, `parking`, `price`.

## Workflow
```text
Load → Explore → Clean → Engineer Features → Preprocess
→ Split → Train Models → Cross-Validate → Evaluate → Compare
```

## Models
Compare:
1. Linear Regression
2. Decision Tree Regressor
3. Random Forest Regressor

## Metrics
Use MAE, RMSE, and R².

## Questions
- Which features appear useful?
- Which model performs best?
- Does cross-validation support the result?
- Is there evidence of overfitting?
- Which model would you choose and why?

## Deliverables
- Notebook
- Dataset description
- Model comparison table
- At least two visualizations
- Final conclusion and limitations

Do not choose a model from one lucky split alone; consider validation stability and the project's objective.


## Syllabus Focus

Regression project using preprocessing, feature engineering, Linear Regression, Decision Tree and Random Forest.
