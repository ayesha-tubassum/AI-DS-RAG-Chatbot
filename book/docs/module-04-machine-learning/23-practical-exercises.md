# Module 04 Practical Exercises

1. Identify each task as regression, classification, or clustering: house price, spam detection, customer grouping, sales prediction, fraud detection.
2. Load a CSV and report shape, types, missing values, and duplicates.
3. Create three meaningful derived features.
4. Build a preprocessing pipeline with numerical imputation, scaling, and categorical encoding.
5. Create an 80/20 train/test split and explain why test data stays unseen.
6. Train Linear Regression and report MAE, RMSE, and R².
7. Train Logistic Regression and Decision Tree; compare precision, recall, F1, and accuracy.
8. Compare a Decision Tree with Random Forest.
9. Test several K values for KNN and select one using validation.
10. Compare linear and RBF SVM after scaling.
11. Apply K-Means to a customer dataset and justify K.
12. Apply Agglomerative Clustering and interpret the groups.
13. Apply PCA and report explained variance.
14. Complete one mini project from raw data to final model evaluation.

### Challenge
Choose a real dataset and document every modeling decision, including why you selected your features, preprocessing, metric, and final model.
