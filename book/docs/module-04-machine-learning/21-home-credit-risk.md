# Home Project — Credit Risk Scoring Model

## Goal
Estimate whether an applicant belongs to a predefined credit-risk category.

## Possible Features
Income, existing debt, loan amount, repayment history, employment information, and account history.

## Tasks
- Define the target clearly.
- Inspect class balance.
- Clean and preprocess.
- Train a baseline.
- Compare at least two additional models.
- Evaluate precision, recall, F1, and confusion matrix.
- Perform error analysis.
- Document limitations.

## Responsible Use
Financial predictions can affect people. A production system requires appropriate validation, fairness checks, governance, interpretability, monitoring, and human oversight.

## Deliverables
Notebook, model comparison, evaluation report, error analysis, and responsible-use section.


## Syllabus Focus

Classification project with responsible-use considerations.
