## Review Questions
1. What is an ML pipeline?
2. What is feature engineering?
3. What is data leakage?
4. Why split training and test data?
5. What is cross-validation?
6. Regression vs classification?
7. When is Linear Regression useful?
8. What does Logistic Regression do?
9. How does a Decision Tree work?
10. Why use Random Forest?
11. What is boosting?
12. Why does KNN need scaling?
13. What is an SVM margin?
14. What is unsupervised learning?
15. How does K-Means work?
16. What does hierarchical clustering provide?
17. Why use PCA?
18. Why compare multiple metrics?

## Completion Checklist
- [ ] I understand the ML pipeline.
- [ ] I can perform basic feature engineering.
- [ ] I can handle missing and categorical data.
- [ ] I can scale numerical features.
- [ ] I can build a preprocessing pipeline.
- [ ] I understand train/test split and cross-validation.
- [ ] I can train regression and classification models.
- [ ] I can compare models with appropriate metrics.
- [ ] I can perform K-Means and hierarchical clustering.
- [ ] I can apply PCA.
- [ ] I completed at least one class project.
- [ ] I completed at least one home project.

## Final Challenge
Build one complete ML project with:
1. Problem statement
2. Dataset description
3. EDA
4. Feature engineering
5. Preprocessing
6. Train/test strategy
7. At least three models
8. Evaluation
9. Model comparison
10. Error analysis
11. Final recommendation
12. Limitations
