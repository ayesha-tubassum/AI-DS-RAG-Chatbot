# Class Project — Fraud Detection Model

## Goal
Build a model that identifies potentially fraudulent transactions.

Fraud datasets can be highly imbalanced. For example, fraud may represent only 1% of transactions.

## Workflow
```text
Explore Class Balance → Clean → Split Carefully → Train
→ Evaluate → Inspect False Positives/Negatives
```

## Models
Try Logistic Regression, Decision Tree, Random Forest, and/or Gradient Boosting.

## Metrics
Focus on precision, recall, F1-score, confusion matrix, and PR-AUC where appropriate.

## Questions
- How many fraudulent cases were found?
- How many legitimate transactions were flagged?
- Which error is more costly?
- What happens when the decision threshold changes?

## Deliverables
Class-distribution chart, preprocessing pipeline, model comparison, confusion matrix, error analysis, and written recommendation.


## Syllabus Focus

Imbalanced classification project focused on precision, recall, F1 and error analysis.
