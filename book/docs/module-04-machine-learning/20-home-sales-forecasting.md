# Home Project — Sales Forecasting

## Goal
Use historical sales data to build a forecasting-oriented ML solution.

## Possible Fields
`date`, `product`, `region`, `sales`, `units`, `price`.

## Tasks
1. Sort observations chronologically.
2. Explore trend and seasonality.
3. Create time-related features.
4. Use a chronological train/test strategy.
5. Train a baseline and ML model.
6. Evaluate later observations.
7. Plot actual vs predicted values.

## Important Rule
Do not randomly mix future observations into training when the goal is future prediction.

## Deliverables
EDA, feature-engineering explanation, model training, forecast chart, MAE/RMSE, and limitations.


## Syllabus Focus

Forecast-oriented ML project using chronological data and time-based evaluation.
