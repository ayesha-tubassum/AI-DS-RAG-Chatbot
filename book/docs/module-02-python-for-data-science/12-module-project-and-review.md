# Module 02 Final Review and Capstone Guidance

## Module Overview

This module introduced the core Python tools used for practical data analysis:

- NumPy
- Pandas
- Data cleaning
- Missing-value handling
- Merging
- GroupBy
- Matplotlib
- Seaborn
- Plotly

The projects then connected these skills to real-world analytical tasks.

## Final Capstone Challenge

Build a complete exploratory data analysis project using a dataset of your choice.

### Required Workflow

```text
Dataset
   ↓
Load
   ↓
Inspect
   ↓
Clean
   ↓
Handle Missing Values
   ↓
Transform
   ↓
Aggregate
   ↓
Visualize
   ↓
Interpret
   ↓
Report
```

## Required Components

Your project must include:

### 1. Dataset Description

Explain:

- What the dataset represents.
- What each important column means.
- What analytical questions you want to answer.

### 2. Data Inspection

Use appropriate Pandas commands to understand the structure.

### 3. Cleaning

Document:

- Missing-value decisions.
- Duplicate handling.
- Data-type corrections.
- Text standardization where necessary.

### 4. Analysis

Use:

- Filtering.
- GroupBy.
- Aggregation.
- Feature creation.
- Merging when appropriate.

### 5. Visualization

Include at least three meaningful charts.

Use the visualization library that best fits each analytical purpose.

### 6. Findings

Write findings in plain language.

A finding should answer a question, not simply describe a chart.

### 7. Limitations

Explain what the dataset or analysis cannot prove.

## Final Review Questions

1. Why is NumPy useful in data science?
2. What is the purpose of a Pandas DataFrame?
3. Why should raw data be inspected before analysis?
4. What are common ways to handle missing values?
5. What is the purpose of merging datasets?
6. How does `groupby()` support analysis?
7. When would you use a line chart instead of a bar chart?
8. What is the difference between exploratory analysis and simply displaying data?
9. What makes a visualization useful?
10. Why should analytical conclusions be connected to evidence?

## Professional Practice

Data science is not only about writing code. A professional analyst should be able to explain:

> What was the question, what data was used, what was done to the data, what was discovered, and how confident should we be in the result?

If you can answer those questions clearly, you are developing the analytical thinking required for the next modules.
