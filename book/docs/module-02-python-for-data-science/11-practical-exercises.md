# Module 02 Practical Exercises

These exercises reinforce the core skills from NumPy, Pandas, data cleaning, missing values, merging, GroupBy, and visualization.

## Exercise 1 — NumPy Statistics

Create a NumPy array containing 10 student scores.

Calculate:

- Mean
- Minimum
- Maximum
- Standard deviation

## Exercise 2 — Array Transformation

Create an array of product prices and apply a 10% discount using a vectorized operation.

## Exercise 3 — DataFrame Creation

Create a DataFrame with:

- Student name
- Age
- Marks
- City

Print the first five rows and basic information.

## Exercise 4 — Filtering

From a student DataFrame, select students whose marks are greater than or equal to 80.

## Exercise 5 — Feature Creation

Create a `Total` column using:

```text
quantity × price
```

## Exercise 6 — Duplicate Detection

Create a DataFrame containing duplicate rows. Detect and remove the duplicates.

## Exercise 7 — Missing Values

Create a DataFrame containing missing numerical and categorical values. Detect them and choose reasonable treatment strategies.

## Exercise 8 — GroupBy

Create sales data for multiple cities and calculate total sales for each city.

## Exercise 9 — Merge

Create separate customer and order DataFrames and merge them using a shared customer ID.

## Exercise 10 — Visualization

Create:

- A line chart.
- A bar chart.
- A scatter plot.

Write one sentence explaining what each chart communicates.

## Exercise 11 — Seaborn

Use Seaborn to create a histogram and a box plot from a numerical dataset.

## Exercise 12 — Plotly

Create an interactive bar chart showing category-level sales.

## Exercise 13 — Mini EDA

Choose a small public dataset and complete:

1. Loading.
2. Inspection.
3. Cleaning.
4. Summary statistics.
5. GroupBy analysis.
6. Three visualizations.
7. Written conclusions.

## Challenge

Combine at least two datasets, clean the combined data, calculate grouped statistics, and create an interactive visualization.

## Submission Standard

Every exercise should contain readable code and a short explanation of the result. Do not submit code without demonstrating that you understand its output.
