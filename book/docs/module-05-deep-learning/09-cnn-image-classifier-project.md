# Class Project — CNN-Based Image Classifier

## Goal
Classify images using a Convolutional Neural Network, as specified in the syllabus.

## Suggested Workflow
```text
Collect Images
→ Organize Classes
→ Resize/Normalize
→ Train/Validation/Test
→ Build CNN
→ Train
→ Evaluate
→ Inspect Errors
```

## Starter Architecture
Use convolution, pooling, and dense layers. Begin with a small model and improve it systematically.

## Deliverables
- Dataset description
- Class distribution
- Sample image visualization
- CNN architecture
- Training/validation curves
- Test metrics
- Confusion matrix
- Misclassification analysis
- Final report

## Questions
1. Which classes are easiest to distinguish?
2. Where does the model fail?
3. Is there evidence of overfitting?
4. Does augmentation help?
