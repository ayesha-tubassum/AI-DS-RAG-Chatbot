# Module 05 Practical Exercises

1. Write the equation for a single perceptron.
2. Explain forward propagation in your own words.
3. Explain why activation functions are necessary.
4. Compare MSE and cross-entropy conceptually.
5. Build a small binary-classification network in Keras.
6. Train the network and plot training/validation loss.
7. Demonstrate overfitting with an intentionally oversized model.
8. Add early stopping and compare results.
9. Build a small CNN for image classification.
10. Explain convolution, pooling, and feature extraction.
11. Load a pre-trained ResNet or VGG model and freeze its backbone.
12. Clean and tokenize a small text dataset.
13. Build an embedding + LSTM classifier.
14. Compare an LSTM with a GRU.
15. Perform error analysis on incorrect image or text predictions.

### Challenge
Choose an image or text dataset and create a complete deep-learning experiment report.
