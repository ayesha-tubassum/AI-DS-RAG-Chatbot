# Home Project — Dogs vs Cats Classification

## Goal
Build a deep-learning image classifier that distinguishes dogs from cats.

## Tasks
1. Organize the image dataset.
2. Split into training, validation, and test sets.
3. Resize and normalize images.
4. Build a CNN baseline.
5. Add augmentation.
6. Evaluate the model.
7. Optionally compare with transfer learning.

## Evaluation
Use accuracy plus precision, recall, F1-score, and a confusion matrix.

## Deliverables
- Notebook
- Dataset explanation
- Sample images
- CNN architecture
- Training curves
- Evaluation
- Error analysis
- Optional ResNet/VGG comparison

## Challenge
Investigate which visual characteristics appear in common misclassifications.
