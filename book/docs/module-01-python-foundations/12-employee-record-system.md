# Home Project — Employee Record System

## Project Goal

Create an employee record system that uses file handling.

The system should allow a user to:

- Add employee records.
- View records.
- Search for employees.
- Store records in a file.

## Suggested Record

```text
Employee ID
Name
Department
Salary
```

## Suggested Program Structure

```python
def add_employee():
    pass


def view_employees():
    pass


def search_employee():
    pass
```

The functions can work with a text file or another simple persistent format.

## Suggested Menu

```text
1. Add Employee
2. View Employees
3. Search Employee
4. Exit
```

## Learning Outcome

This project combines functions, conditions, loops, file handling, and structured data into a small application.

## Extension Challenges

After completing the basic version, add:

1. Update employee records.
2. Delete an employee.
3. Search by department.
4. Calculate average salary.
5. Validate employee input.
6. Convert the record structure into a class.
