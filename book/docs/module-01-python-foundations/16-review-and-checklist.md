# Module Review and Completion Checklist

## Key Takeaways

After completing Python Foundations, you should understand the basic building blocks required to write Python programs.

You should now be able to:

- Store information using variables.
- Work with common Python data types.
- Perform calculations and comparisons.
- Make decisions with conditional statements.
- Repeat operations using loops.
- Create reusable functions.
- Import modules.
- Work with lists, tuples, dictionaries, and sets.
- Read and write files.
- Handle common runtime errors.
- Create classes and objects.
- Apply OOP concepts to small applications.
- Build beginner-level Python projects.

These concepts form the foundation for the next stage of the syllabus: **Python for Data Science**, where Python will be used with NumPy, Pandas, and visualization tools.

## Module Review Questions

1. What is the difference between a variable and a data type?
2. Explain the difference between `if`, `elif`, and `else`.
3. When would you use a `for` loop instead of a `while` loop?
4. Why are functions important in software development?
5. What is the difference between a list, tuple, dictionary, and set?
6. Why is file handling important?
7. What is an exception?
8. How does exception handling improve a program?
9. What is a class?
10. What is an object?
11. Explain inheritance in simple terms.
12. Why is OOP useful when building real-world applications?
13. Which Python concepts are used in the Student Management System?
14. Design a simple Library Management System on paper before implementing it.
15. What concepts from this module will be useful in Data Science?
