# Final Project — Python Student Management System

## Project Goal

Build a complete beginner-level Student Management System.

This final project combines the main programming concepts introduced throughout Module 01.

## Required Features

The system should allow the user to:

1. Add a student.
2. View students.
3. Search for a student.
4. Calculate a student's grade.
5. Update student information.
6. Store information persistently.
7. Handle invalid input.
8. Exit the application.

## Recommended Concepts

The project should use:

- Variables
- Data types
- Conditions
- Loops
- Functions
- Lists and/or dictionaries
- File handling
- Exception handling
- Classes and objects

## Suggested Architecture

```text
Student Management System
│
├── Student Class
├── Add Student
├── View Students
├── Search Student
├── Update Student
├── Calculate Grade
├── Save Records
└── Load Records
```

## Suggested Development Steps

### Step 1 — Create the Student Model

Create a `Student` class containing the information needed for each student.

### Step 2 — Add Students

Create functionality that accepts student information and stores it.

### Step 3 — Display Students

Create functionality that displays all available records.

### Step 4 — Search

Allow the user to search by student ID or another unique field.

### Step 5 — Calculate Grades

Create a method that calculates the student's grade from their marks.

### Step 6 — Persistent Storage

Save records to a file and load them when the program starts.

### Step 7 — Input Validation

Handle invalid input so that the application does not terminate unexpectedly.

## Project Challenge

After completing the basic version, add:

- Multiple subjects.
- Average marks.
- Highest-performing student.
- Lowest-performing student.
- Search by student ID.
- Input validation.
- A report showing the class average.

## Completion Criteria

A successful project should be understandable, organized, and usable from the command line.

The student should be able to explain which Python concepts were used and why each part of the program exists.
