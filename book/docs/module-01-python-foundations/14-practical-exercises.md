# Practical Exercises

These exercises are designed to reinforce the concepts covered in Module 01.

## Exercise 1 — Student Information

Create variables for:

- Name
- Age
- Course
- Marks

Print them in a readable format.

## Exercise 2 — Calculator

Create a program that accepts two numbers and performs:

- Addition
- Subtraction
- Multiplication
- Division

## Exercise 3 — Grade Calculator

Ask the user for marks and display an appropriate grade.

## Exercise 4 — Number Loop

Print numbers from 1 to 100.

Then modify the program so that it prints only even numbers.

## Exercise 5 — Function Practice

Create a function:

```python
def calculate_area(length, width):
    return length * width
```

Call the function with different values.

## Exercise 6 — Data Structures

Create a dictionary representing a student and print each field.

## Exercise 7 — File Practice

Create a file and store the names of five students.

Read the file and display the names.

## Exercise 8 — Exception Handling

Ask the user to enter a number. Handle invalid input without crashing the program.

## Exercise 9 — OOP Practice

Create a `Book` class with:

- Title
- Author
- Price

Add a method that displays the book information.

## Exercise 10 — Mini Menu

Create a menu-driven program that allows a user to choose between several operations and continues until the user selects Exit.
