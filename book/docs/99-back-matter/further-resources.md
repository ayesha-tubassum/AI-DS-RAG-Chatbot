# Further Resources

## Official Python Documentation

The most authoritative source for Python is the official documentation at **python.org**.

It includes:

- The Python Tutorial — a guided introduction to the language.
- The Library Reference — documentation for every standard library module.
- The Language Reference — the formal specification of Python syntax and semantics.
- How-to guides for common tasks.

All of these are free, up to date, and maintained by the Python Software Foundation.

## How to Use the Documentation

When you encounter a new function, module, or error:

1. Go to python.org and choose **Documentation**.
2. Use the search box or browse the table of contents.
3. Read the examples. They are short and practical.

The tutorial is a good next step after Module 01. It revisits the basics and then moves beyond them.

## No Other Links

This book intentionally avoids linking to third-party tutorials, videos, or courses. Links change, content quality varies, and a beginner can spend more time choosing a resource than learning.

Start with the official documentation. When you are ready for more, you will know what to search for.
