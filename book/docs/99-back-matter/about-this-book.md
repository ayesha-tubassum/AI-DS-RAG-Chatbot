# About This Book

## What This Book Is

This book is a practical introduction to programming, data science, and intelligent systems. It is written for beginners and assumes no prior experience.

The content is organised into modules. Each module introduces new concepts, provides examples, and ends with hands-on exercises or a project. You learn by writing code, not just reading about it.

## How It Is Built

This book is published with **Docusaurus**, an open-source static site generator.

- The source files are Markdown documents in a `docs` folder.
- Each module is a subfolder. Front matter and back matter are separate folders.
- The sidebar is generated automatically from the folder structure and the `_category_.json` files.
- The theme provides navigation, search, and a clean reading experience.
- The site is built as static HTML, CSS, and JavaScript, so it can be hosted anywhere.

## Why Docusaurus

- It treats documentation as code — versionable, reviewable, and collaborative.
- It supports Markdown with front matter for metadata (title, sidebar position, IDs).
- It handles code highlighting, search, and dark mode out of the box.
- It is widely used for technical documentation and books.

## No Fake Author Information

This book does not attribute authorship to a specific person or institution. It is a collaborative, evolving resource. The focus is on the material, not the messenger.

If you find an error or want to suggest an improvement, the source is available for contributions.
