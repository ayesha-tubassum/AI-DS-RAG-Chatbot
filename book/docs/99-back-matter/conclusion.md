# Conclusion

## What You Have Learned

You started this book with no programming experience. Now you can:

- Write and run Python programs in VS Code.
- Store and work with data using variables, lists, tuples, dictionaries, and sets.
- Make decisions with conditional statements and repeat actions with loops.
- Organise code into functions and modules.
- Read from and write to files.
- Handle errors so your programs do not crash unexpectedly.
- Build classes and objects, and understand inheritance and encapsulation.
- Complete small projects that bring several ideas together.

## How Far You Have Come

The first module was the longest because it introduced the building blocks of programming. Each concept was new. By now, the basics feel more familiar. The code you write will still have bugs, but you know how to read the error messages and fix them.

## Keep Going

The skills in Module 01 are the foundation for everything that follows. The next modules will show you how to use Python for data science, statistics, machine learning, and beyond.

Programming is learned by doing. The more you write, the more natural it becomes. Return to the exercises and projects whenever you want to practise.

Thank you for reading this far. The next chapter is yours to write.
