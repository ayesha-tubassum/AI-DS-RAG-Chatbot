# Glossary

This glossary defines terms used in Module 01: Python Foundations. Terms are listed alphabetically.

## A

**argument** — A value passed to a function when it is called.

## C

**class** — A blueprint for creating objects. A class defines attributes and methods that the created objects will have.

**comment** — Text in a program that is ignored by Python. It starts with `#` and is used to explain the code.

## D

**data type** — A category that determines what kind of value a variable holds and what operations can be performed on it. Common types in Module 01: integer, float, string, boolean, list, tuple, dictionary, set.

**dictionary** — A mutable collection of key-value pairs. Keys must be unique and immutable. Created with curly braces: `{"name": "Ali", "age": 20}`.

## E

**encapsulation** — Bundling data and the methods that operate on that data inside a class, and restricting direct access to some of the object's components.

**exception** — An event that occurs during program execution and disrupts the normal flow. Examples: `ValueError`, `ZeroDivisionError`, `FileNotFoundError`. Handled with `try` and `except`.

## F

**float** — A data type representing decimal numbers. Example: `3.14`.

**function** — A reusable block of code that performs a specific task. Defined with `def`, optionally takes parameters, and may return a value.

## I

**inheritance** — A mechanism where a new class (child) derives attributes and methods from an existing class (parent).

**integer** — A data type representing whole numbers. Example: `42`.

## L

**list** — A mutable, ordered collection of items. Created with square brackets: `[1, 2, 3]`. Items can be of different types.

**loop** — A construct that repeats a block of code. Module 01 covers `for` loops and `while` loops.

## M

**method** — A function defined inside a class that operates on instances of that class.

**module** — A Python file containing definitions and statements that can be imported into other files using `import`.

## O

**object** — An instance of a class. It has the attributes and methods defined by its class.

**operator** — A symbol that performs an operation on one or more values. Examples: `+`, `-`, `*`, `/`, `==`, `and`, `or`.

## P

**parameter** — A variable in a function definition that receives an argument when the function is called.

## S

**set** — An unordered collection of unique items. Created with curly braces: `{1, 2, 3}`. No duplicate values allowed.

**string** — A data type representing text. Written inside quotes: `"hello"` or `'hello'`.

## T

**tuple** — An immutable, ordered collection of items. Created with parentheses: `(1, 2, 3)`. Cannot be changed after creation.

## V

**variable** — A named reference to a value. Created by assignment: `name = "Ali"`. The name can later refer to a different value.
