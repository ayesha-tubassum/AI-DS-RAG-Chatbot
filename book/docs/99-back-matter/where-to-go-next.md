# Where to Go Next

You have finished the first module. Here is a general learning path for what comes after.

## Next Modules in This Book

When the remaining modules are available, they build on your Python foundations in this order:

1. **Python for Data Science** — NumPy, pandas, data cleaning, visualisation, and small data projects.
2. **Statistics and Math for ML** — Descriptive statistics, probability, distributions, and the math behind machine learning.
3. **Machine Learning** — Supervised and unsupervised learning, model evaluation, and practical projects.
4. **Deep Learning** — Neural networks, frameworks, and common architectures.
5. **MLOps** — Packaging, deploying, and monitoring models.
6. **Big Data and Cloud** — Distributed computing, cloud platforms, and large-scale data pipelines.
7. **Generative AI and LLMs** — Large language models, prompt engineering, and retrieval-augmented generation.
8. **Agentic AI** — Autonomous agents, tool use, and multi-agent systems.

## General Learning Suggestions

While you wait for the next modules, you can strengthen your skills in these areas:

### Deeper Python

- Read the official Python tutorial at python.org.
- Practise writing small scripts for everyday tasks (renaming files, converting data formats, automating simple work).
- Explore the standard library modules you have not yet used.

### Data Practice

- Find open datasets (for example, from government portals or community repositories).
- Load them with pandas, clean them, and make simple charts.
- Ask questions of the data and answer them with code.

### Projects

- Build a small program that solves a real problem for you.
- Share the code in a public repository.
- Write a short note about what you built and what you learned.

## A Note on Pace

There is no rush. A solid grasp of the fundamentals makes the advanced topics much easier. Revisit Module 01 whenever something feels unclear. Consistency beats intensity.
