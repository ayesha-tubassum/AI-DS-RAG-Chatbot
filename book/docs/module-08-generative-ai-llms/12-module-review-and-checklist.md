# Module Review and Completion Checklist

## Transformers and LLMs

- [ ] I understand the purpose of Transformers.
- [ ] I can explain self-attention conceptually.
- [ ] I understand the high-level difference between BERT and GPT.
- [ ] I understand tokenization.

## Prompt Engineering

- [ ] I can write clear prompts.
- [ ] I can provide context and constraints.
- [ ] I can use examples when appropriate.
- [ ] I can request structured outputs.
- [ ] I understand that prompts do not guarantee factual accuracy.

## Fine-Tuning

- [ ] I understand why fine-tuning is used.
- [ ] I understand LoRA conceptually.
- [ ] I understand QLoRA conceptually.
- [ ] I can explain when RAG may be preferable to fine-tuning.

## RAG and Vector Search

- [ ] I understand document chunking.
- [ ] I understand embeddings.
- [ ] I understand vector similarity search.
- [ ] I understand FAISS and Pinecone at a conceptual level.
- [ ] I can design a basic RAG pipeline.
- [ ] I can evaluate retrieval and answer quality.

## Projects

- [ ] ChatGPT-style Q/A Bot completed.
- [ ] RAG System with Vector Database completed.
- [ ] Domain-Fine-Tuned Q/A LLM completed.
- [ ] Text Summarization or Content Generator completed.

## Final Mental Model

```text
User Question
      ↓
Prompt / Retrieval
      ↓
Relevant Context
      ↓
Transformer LLM
      ↓
Generated Response
      ↓
Evaluation / Sources
```
