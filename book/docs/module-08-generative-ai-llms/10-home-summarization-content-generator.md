# Home Project — Text Summarization or Content Generator

## Goal

Build an AI tool that summarizes text or generates controlled content.

Choose one:

- Article summarizer
- Meeting-note summarizer
- Study-note generator
- Product-description generator
- Social-content generator
- Report-outline generator

## Requirements

1. Define the target user.
2. Define input format.
3. Create a prompt template.
4. Generate outputs.
5. Add validation or formatting.
6. Test multiple inputs.
7. Evaluate quality and factual consistency.

## Suggested Evaluation

For summaries, check:

- Coverage of important information
- Conciseness
- Factual consistency
- Organization

For generated content, check:

- Instruction following
- Relevance
- Tone
- Repetition
- Unsupported claims

## Deliverables

- Working application
- Prompt templates
- Test dataset
- Evaluation examples
- README
