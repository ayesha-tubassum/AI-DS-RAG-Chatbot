# Practical Exercises

## Beginner

1. Explain what a Transformer is.
2. Explain self-attention in simple language.
3. Compare BERT and GPT conceptually.
4. Explain tokenization.
5. Write a structured prompt for summarization.
6. Explain embeddings.

## Intermediate

7. Design a RAG pipeline.
8. Explain why chunking matters.
9. Compare FAISS and a managed vector database.
10. Create a prompt with examples and structured output.
11. Design metadata for retrieved documents.
12. Compare RAG and fine-tuning.

## Advanced

13. Build a small vector-search demonstration.
14. Build a Q/A chatbot.
15. Build a RAG prototype.
16. Design an evaluation set for hallucination and retrieval quality.
17. Design a LoRA/QLoRA fine-tuning experiment.

## Reflection

For each task, record:
- What you built
- What worked
- What failed
- How you evaluated it
- What you would improve
