# Class Project — ChatGPT-Style Q/A Bot

## Goal

Build an interactive question-answering application using an LLM.

## Architecture

```text
User
 ↓
Chat Interface
 ↓
Prompt
 ↓
LLM
 ↓
Response
```

## Requirements

1. Create a simple chat interface.
2. Accept user questions.
3. Construct a clear prompt.
4. Send the request to an LLM.
5. Display the response.
6. Handle errors gracefully.
7. Document limitations.

## Optional Improvements

- Conversation history
- System instructions
- Structured output
- Response streaming
- Basic input validation

## Evaluation

Test questions should include:

- Easy factual questions
- Ambiguous questions
- Out-of-scope questions
- Requests requiring structured answers

Record examples where the model gives an incorrect or uncertain answer.

## Deliverables

- Application code
- README
- Screenshots/demo
- Test cases
- Short evaluation report
