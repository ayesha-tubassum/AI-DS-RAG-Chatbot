# Who Is This Book For?

This book is written for beginners. You do not need a degree, a special background, or prior experience with programming.

## Your Background

This book is suitable for anyone who wants to start a path in data science or intelligent systems. You might be:

- A student beginning to explore computers and data.
- Someone changing career and wanting a practical introduction.
- A self-learner who enjoys working through hands-on examples.
- Anyone who is curious about how software can analyse data or make predictions.

You can follow the chapters in order, from the very first page.

## Prerequisites

### For Python

No programming experience is required. You should know how to:

- Turn on a computer and use a basic editor or file manager.
- Type on a keyboard.
- Save a file in a folder you can find again.

All programming ideas are introduced from the start in the first module.

### For the Later Modules

The modules build on one another. Before each later module, the relevant Python skills are assumed to be covered in an earlier module. Nothing here requires advanced mathematics or prior data science knowledge.

## How Much Time You Need

You can learn at your own pace. Some readers spend a week on a single module; others spend more. The important thing is steady practice, not speed.

Consistency matters more than intensity. Fifteen minutes of typing code each day will take you further than a single long session once a month.

## A Note on Confidence

You will meet moments when the code does not work. This happens to every programmer, including experts. Each mistake is a chance to learn how the computer really thinks. Keep going.
