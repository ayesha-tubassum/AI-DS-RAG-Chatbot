# Preface

## Why This Book Exists

Welcome. If you have ever opened a programming book and felt lost by the time you reached the second chapter, this book was written for you.

Learning to program can feel overwhelming at first. There are new words, new symbols, and new ways of thinking. A lot of online material assumes you already know some of these things. This book starts from the very beginning.

## What You Will Gain

By the end of this book, you will have a solid foundation for working with data and intelligent systems. More specifically, you will be able to:

- Write and run your own Python programs.
- Read, clean, and understand data.
- Use tools that are standard in data science, such as **NumPy**, **pandas**, and **matplotlib**.
- Build simple machine learning models and see how they make predictions.
- Understand the basics of deep learning, generative AI, and agentic systems.
- Finish a hands-on project that puts several ideas together.

Every chapter includes examples, review questions, and projects. You learn programming by doing, so try each example yourself before reading the answer.

## How This Book Is Different

This book is practical from the start. You will not spend weeks learning theory before writing code. You will see working programs early, understand what they do, and then add a little more at a time. When you feel stuck, look at the review questions and the project checklist. They show you exactly what to practise.

You do not need any previous programming experience. You do need curiosity, and a willingness to type, run, and experiment.

## A Note on Practice

Programming is a skill, not just knowledge. The more you type code, the more natural it becomes. Keep this book open while you work. Save your own programs in a folder. Return to the earlier chapters when you need a reminder.

Thank you for starting this journey. Let us begin.
