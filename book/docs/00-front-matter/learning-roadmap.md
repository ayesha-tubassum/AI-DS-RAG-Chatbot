# Learning Roadmap

This book is organised as a sequence of modules. Each module adds new ideas and ends with a project.

## Current Module

### Module 01: Python Foundations — Available Now

Python is the main language used in this book. In this module you will learn:

- Variables and data types
- Operators and conditional statements
- Loops and iterations
- Functions, lambda functions, and modules
- Python data structures such as lists, tuples, sets, and dictionaries
- File handling
- Exception handling
- Object-oriented programming
- Practical exercises
- A final project

This module is complete and ready to read.

## Suggested Order

For most readers, the best approach is to read the modules in the order listed above. Each module builds on the one before it, and the projects become more challenging as you progress.

If you are following this roadmap, begin with Module 01 and move through the available modules in order.
