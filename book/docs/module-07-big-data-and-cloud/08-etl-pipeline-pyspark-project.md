# Class Project — ETL Pipeline Using PySpark

## Goal

Build an end-to-end ETL pipeline using PySpark.

**ETL = Extract → Transform → Load**

```text
Raw Data → Extract → PySpark DataFrame → Transform → Validate/Clean → Load
```

## Requirements

1. Load a dataset with PySpark.
2. Inspect schema and missing values.
3. Clean or transform selected columns.
4. Perform at least one aggregation.
5. Save the processed result.
6. Document the pipeline.
7. Explain why Spark is useful for larger datasets.

## Deliverables

- PySpark script or notebook
- Input dataset description
- Transformation documentation
- Output dataset
- README
- Architecture diagram
