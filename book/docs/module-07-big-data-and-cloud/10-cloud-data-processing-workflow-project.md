# Class Project — Cloud-Based Data Processing Workflow

## Goal

Design and, where resources allow, implement a cloud-based data-processing workflow.

## Requirements

- Cloud object storage
- Distributed processing component
- Processed output
- Basic access/security plan
- Documentation
- Optional ML step

```text
Data Source → Cloud Storage → Spark / Databricks / EMR
           → Processed Data → Analytics / ML → Report or Model
```

## Deliverables

1. Architecture diagram
2. Configuration/setup notes
3. Processing code
4. Sample input/output
5. Security considerations
6. Cost considerations
7. Final report

Never expose cloud access keys in a repository.
