# Home Project — Big Data Batch Processing

## Goal

Process a large or realistically simulated dataset as a scheduled batch workload.

## Tasks

1. Select a dataset.
2. Explain why batch processing is appropriate.
3. Load the data using Spark.
4. Perform transformations.
5. Generate summary statistics.
6. Save processed output.
7. Measure or discuss processing performance.

Suggested use cases include sales records, web activity logs, transaction data, and sensor readings.

## Stretch Goal

Compare a small version of the task in Pandas and PySpark and discuss setup, execution, and scalability differences.
