# Practical Exercises

## Beginner

1. Define Big Data in your own words.
2. Explain the purpose of HDFS.
3. Describe MapReduce using a word-count example.
4. Explain the role of YARN.
5. Define an RDD.
6. Create a small Spark DataFrame.
7. Run a Spark SQL aggregation.

## Intermediate

8. Build an RDD transformation pipeline.
9. Load a CSV into a Spark DataFrame and clean it.
10. Create a Spark SQL query with `GROUP BY`.
11. Build a simple MLlib classification workflow.
12. Design an S3-style data lake structure.
13. Explain object storage vs virtual compute.

## Advanced

14. Build the PySpark ETL project.
15. Train an MLlib model.
16. Design a cloud-based Spark workflow.
17. Compare batch and streaming architectures.
18. Explain when distributed processing may not be worth its overhead.

For every task, document what you built, what failed, how you fixed it, and what you learned.
