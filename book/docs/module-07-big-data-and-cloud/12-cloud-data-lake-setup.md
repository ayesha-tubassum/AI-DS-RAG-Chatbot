# Home Project — Cloud-Based Data Lake Setup

## Goal

Design and set up a basic cloud data lake structure.

```text
data-lake/
├── raw/
├── cleaned/
├── curated/
├── models/
└── reports/
```

## Tasks

1. Choose AWS or Azure.
2. Create the appropriate storage resource.
3. Organize data into logical layers.
4. Upload sample data.
5. Document access permissions.
6. Explain how Spark would process the data.
7. Describe how processed results would be consumed.

Never commit cloud credentials to Git. Remove unused resources to avoid unexpected charges.
