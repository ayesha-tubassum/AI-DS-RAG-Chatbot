# Optional Home Project — Real-Time Processing Mini Project

The syllabus lists real-time processing as an optional mini project.

## Goal

Explore the difference between batch and real-time data processing.

```text
Event 1 → Event 2 → Event 3 → Event 4
                    ↓
              Processing Layer
                    ↓
               Live Results
```

Possible examples include website activity, IoT sensor events, or transaction events.

## Tasks

1. Define the event schema.
2. Explain why streaming is useful.
3. Design the processing flow.
4. Implement a small demonstration if your environment supports it.
5. Compare it with batch processing.

## Deliverables

- Architecture diagram
- Event schema
- Demo or pseudocode
- Batch vs streaming comparison
