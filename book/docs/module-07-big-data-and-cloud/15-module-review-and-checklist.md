# Module Review and Completion Checklist

## Big Data

- [ ] I understand why distributed processing is useful.
- [ ] I understand Hadoop conceptually.
- [ ] I can explain HDFS.
- [ ] I can explain MapReduce.
- [ ] I understand YARN.

## Spark

- [ ] I understand RDDs.
- [ ] I can distinguish transformations and actions.
- [ ] I can create and query DataFrames.
- [ ] I can use basic Spark SQL.
- [ ] I understand Spark MLlib.

## Cloud

- [ ] I understand object storage such as S3.
- [ ] I understand virtual compute such as EC2.
- [ ] I understand Databricks / EMR.
- [ ] I can describe cloud ML deployment.
- [ ] I understand basic cloud security and cost awareness.

## Projects

- [ ] PySpark ETL Pipeline completed.
- [ ] Spark MLlib Model Training completed.
- [ ] Cloud-Based Data Processing Workflow completed.
- [ ] Big Data Batch Processing completed.
- [ ] Cloud Data Lake Setup completed.
- [ ] Optional real-time mini project explored.

## Final Mental Model

```text
Store Large Data
      ↓
HDFS / Cloud Storage
      ↓
Process at Scale
      ↓
Hadoop / Spark
      ↓
Transform & Analyze
      ↓
Spark SQL / MLlib
      ↓
Cloud Infrastructure
      ↓
Deploy Data & ML Workflows
```
