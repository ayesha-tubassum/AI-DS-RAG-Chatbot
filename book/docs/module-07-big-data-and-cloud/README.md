# Module 07 — Big Data and Cloud

This module follows the uploaded course syllabus for Weeks 31–34.

## Syllabus Coverage

### Week 31 — Big Data
- Hadoop Concepts
- HDFS
- MapReduce
- YARN

### Week 32 — Apache Spark
- RDDs
- DataFrames
- Spark SQL
- Spark MLlib

### Week 33 — Cloud (AWS or Azure)
- S3 Storage
- EC2 Basics
- Databricks / EMR
- Deploying ML Models on Cloud

### Week 34 — Projects

Class-Based:
- ETL Pipeline using PySpark
- Spark MLlib Model Training
- Cloud-Based Data Processing Workflow

Home-Based:
- Big Data Batch Processing
- Cloud-Based Data Lake Setup
- Real-Time Processing Mini Project (Optional)

## Learning Outcome

Understand distributed data processing with Hadoop and Spark, structured processing with DataFrames and SQL, scalable ML with MLlib, and the role of cloud storage and compute in Big Data and ML workflows.
