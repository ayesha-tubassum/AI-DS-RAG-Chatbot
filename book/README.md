# AI & Data Science

A beginner-friendly book website built with Docusaurus.

## Run locally

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```

For deployment, set `DOCUSAURUS_URL` to the public site URL before building. The
local development default is `http://localhost:3000`.

The book content lives in `docs/`. Pages are served at the site root, without a `/docs` URL prefix.
